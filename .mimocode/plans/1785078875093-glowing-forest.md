## Step 5: Upgrade Reports Page with Recharts

**File:** `apps/app/resources/js/Pages/Manager/Reports/Index.jsx`

### Current state
- 4 StatCards (revenue, bookings, occupancy, no-show rate)
- Hand-drawn SVG area chart (revenue by day)
- Summary text
- 2-col grid: no-show stats + top customers

### New design — professional analytics dashboard

**Layout:**

```
┌─────────────────────────────────────────────────────┐
│  Date range filter (From / To / Apply)              │
├─────────┬─────────┬─────────┬───────────────────────┤
│ Doanh thu│ Đặt sân │ Tỷ lệ   │ Tỷ lệ bom            │
│ tổng     │ đã xác  │ lấp đầy │                       │
│ ( StatCard × 4 with trends )                        │
├─────────────────────┬───────────────────────────────┤
│ Xu hướng doanh thu  │  Phân loại đặt sân           │
│ (AreaChart 700x300) │  (PieChart / RadialBarChart)  │
│ Recharts            │  Confirmed/Pending/NoShow     │
├─────────────────────┴───────────────────────────────┤
│  Doanh thu theo ngày trong tuần (BarChart)           │
│  So sánh thứ 2 → CN                                │

└─────────────────────┴───────────────────────────────┘
```

### Charts to implement with Recharts:

1. **Revenue AreaChart** — X=date, Y=revenue (VND). Gradient fill, tooltips with formatted VND, responsive container.
2. **Booking Status PieChart** — Confirmed / Pending deposit / No-show as pie/donut. Colors: emerald/amber/rose.
3. **Revenue by Day-of-Week BarChart** — Aggregate revenue by Mon-Sun. Helps identify peak days.
4. **Hourly Booking Heatmap/BarChart** — Which hours are most booked. Bar chart with hours on X-axis.

### StatCards — enhanced with trend indicators:
- Each card shows a small trend arrow (↑/↓) vs previous period
- Use `TrendingUp` / `TrendingDown` icons from lucide

### Top Customers table:
- Keep existing ranked list with badges
- Add "Tổng chi tiêu" column formatted as VND
- Style as a proper table with alternating row backgrounds

### No-show & Deposit section:
- Keep stats but style as mini stat cards within a section
- Add a progress bar showing deposit collection rate
